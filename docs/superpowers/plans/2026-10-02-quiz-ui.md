# Quiz Studio Implementation Plan

> Execute inline using executing-plans and test-driven-development. User authorized building the UI; no additional permission gates. No Git repository.

**Goal:** UI file/folder với normalize tên input và output tên gốc chính xác.
**Architecture:** FastAPI local + static frontend, job worker dùng pipeline có mapping.
**Tech Stack:** Python 3.10+, FastAPI, uvicorn, python-multipart, HTML/CSS/JS; pytest và Playwright.
**Spec:** `docs/superpowers/specs/2026-10-02-quiz-ui-design.md`

## Global Constraints
- Không sửa `.env`, `prompt.py`, tên tài liệu gốc hoặc schema JSON quiz.
- Normalize trước khi LLM xử lý, giữ mapping gốc và không ghi đè khi tên bỏ dấu trùng.
- Folder output/ZIP giữ đúng root và từng thư mục con của input.
- Nhận nhiều job vào queue FIFO; chỉ một job được xử lý tại mỗi thời điểm, mỗi file một lần gen, key chỉ phía backend.

## Review Focus
- Unicode decomposed, `đ/Đ`, tên khác dấu nhưng trùng sau normalize.
- Folder chỉ có file không hỗ trợ, path traversal/duplicate multipart paths.
- Cancel giữa file/retry; download partial results; restart khi đang chạy.
- Tên file HTML-special characters không gây injection trong UI.
- ZIP chỉ chứa output thành công, cây thư mục và tên gốc nguyên vẹn.

## Tasks
1. Tests normalize/collision và pipeline output mapping/callback/stop; RED → implement `inputs.py` + mở rộng `pipeline.py` → GREEN.
2. Tests multipart jobs/limits/progress/download/restart qua real pipeline + HTTP mock; RED → implement `config.py`, `jobs.py`, `web.py`, `app.py` → GREEN. Thêm deps.
3. Implement frontend upload tabs, tree preview, controls, progress/result table, quiz modal, JSON/ZIP download; kiểm tra bằng browser thật với fake LLM server, sửa lỗi có regression coverage.
4. Update README, test full suite và smoke UI, read-only independent review theo requesting-code-review skill, khởi chạy local UI cho người dùng.
